목표가 분산 분해기

같은 종목을 보는 증권사들의 목표가가 왜 다른가 — 실적 전망 차이인지, 같은 이익에 매기는 멀티플 차이인지, 아니면 오래된 리포트(stale)로 생긴 착시인지를 한 화면에 분해합니다.

설정종목·오늘 주가·기준일

📌 지금 무엇을 하나: 아래는 제가 넣어둔 가짜 샘플입니다. 화면이 어떻게 도는지 먼저 보시고, 준비되면 실제 증권사 리포트 2~3건·오늘 주가·각 리포트 기준일을 주시면 그대로 바꿔 드립니다. 왜 필요한가: '오래된 리포트(stale)' 판정은 오늘 날짜 기준으로 며칠 지났는지를 봐야 하기 때문입니다.
실제 리포트 텍스트 붙여넣기(선택) — 아직은 비워두셔도 됩니다

데모에서는 아래 샘플 객체를 그대로 씁니다. 실제 적용 시 이 칸에 리포트별 (증권사·날짜·목표가·EPS·PER·인용)을 주시면 됩니다. 한 건씩 따로 추출하는 것이 1단계의 핵심입니다.

1단계리포트 한 건씩 — 사실만 추출

📌 지금 무엇을 하나: 리포트를 한 건씩 따로 보면서 본문에 적힌 사실(증권사·날짜·목표가·산식·원문 인용)만 뽑습니다. 왜 이렇게 하나: 여러 건을 한꺼번에 섞으면 한 리포트의 숫자가 옆 리포트로 새어들어 '지어내기'가 생깁니다. 본문에 없으면 null로 비워두고 절대 추정하지 않습니다. 인용은 원문 그대로 옮깁니다.

2단계분산을 '단 하나의 가정'으로 압축 + stale 분리

📌 지금 무엇을 하나: 목표가 = EPS(실적) × PER(멀티플) 입니다. 그래서 목표가들의 흩어짐(분산)을 ‘실적 때문’과 ‘멀티플 때문’ 두 조각으로 쪼갭니다. 왜 중요한가: "다들 목표가가 다르다"가 아니라 "차이의 대부분은 OO 하나 때문"이라고 한 문장으로 말할 수 있어야 의사결정이 됩니다. 그리고 오래된 리포트(stale)는 비율 계산에서 빼고 따로 보여드립니다 — 옛 가정이 섞이면 그림이 왜곡되기 때문입니다.

목표가 분산의 출처 (stale 제외, log 분해)
멀티플(같은 이익, 다른 PER) 실적(EPS 전망 차이)
stale로 따로 뺀 리포트

3단계검증 — 만든 쪽과 분리된 별도 점검

📌 지금 무엇을 하나: 2단계가 만든 분석이 1단계 추출과 어긋나지 않는지, 그리고 버린 값(null·stale)으로 비율을 만들지 않았는지를 따로 다시 셉니다. 왜 분리하나: 분석을 만든 같은 손으로 검증하면 실수를 못 봅니다. 그래서 검증은 추출 원본만 보고 숫자를 처음부터 다시 계산해 일치 여부를 표시합니다.
