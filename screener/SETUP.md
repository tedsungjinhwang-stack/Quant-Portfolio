# 모멘텀 20MA 눌림목 스크리너 — 설치 가이드

매일 아침(07:10 KST) GitHub가 자동으로 돌려서 **미국·한국 대장주 중 20MA에 닿은 종목**을 텔레그램으로 보냅니다. 코드는 안 보셔도 되고, 아래 **딱 2가지(텔레그램 봇, GitHub 시크릿)** 만 한 번 세팅하면 끝입니다.

---

## 1단계 — 텔레그램 봇 만들기 (5분, 무료)

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력 → 봇 이름·아이디 정하면 **봇 토큰**(예: `8123456:AAabc...`)을 줍니다. **복사해 두세요.**
3. 방금 만든 **내 봇**을 검색해 대화 시작하고 아무 말이나 한 번 보냅니다(예: `hi`).
4. **내 chat_id 확인:** 브라우저에서 아래 주소를 열고(토큰 자리에 본인 토큰)
   ```
   https://api.telegram.org/bot<봇토큰>/getUpdates
   ```
   결과에서 `"chat":{"id":123456789` 의 **숫자(123456789)** 가 chat_id 입니다.
   - 안 보이면 봇에게 메시지를 한 번 더 보내고 새로고침하세요.

> 결과로 **봇 토큰**과 **chat_id** 두 값을 얻으면 됩니다.

---

## 2단계 — GitHub 시크릿 등록 (값을 코드에 적지 않음)

GitHub 레포 → **Settings → Secrets and variables → Actions → New repository secret** 에서 2개 추가:

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 1단계의 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 1단계의 chat_id |

> 시크릿은 암호화되어 저장되고 로그에도 안 보입니다. 화면·코드에는 절대 적지 마세요.

---

## 3단계 — 바로 한 번 돌려서 확인

GitHub 레포 → **Actions** 탭 → **Daily Momentum 20MA Pullback Screener** →
오른쪽 **Run workflow** 버튼으로 즉시 실행할 수 있습니다.
- 텔레그램으로 메시지가 오면 성공.
- 결과 파일은 레포의 `reports/latest.md` 와 `reports/momentum-pullback-YYYY-MM-DD.md` 에 매일 쌓입니다.

이후로는 **평일 아침 07:10 KST에 자동**으로 옵니다(직접 안 켜도 됨).

---

## 자주 바꾸는 설정 (`screener/screener.py` 상단 `CONFIG`)

| 항목 | 의미 | 기본값 |
|---|---|---|
| `ma_pullback` | 눌림목 기준 이동평균 | 20일 |
| `ma_trend` | 추세 필터(이 MA 위만 대장주) | 200일 |
| `leaders_per_market` | 시장별 RS 상위 몇 개를 대장주로 | 40 |
| `rs_weights` | RS = 3·6·12개월 수익률 가중 | 0.4 / 0.4 / 0.2 |
| `proximity_pct` | 종가가 20MA ±N%면 '근접' 표기 | 1.0% |
| `kr_top_n` | 한국은 시총 상위 N개만 | 250 |

말로 "20MA 말고 60MA로", "대장주 20개만", "한국만" 처럼 알려주시면 제가 이 값만 바꿔 드립니다.

---

## 눌림목 정의 (현재 로직)

- **터치 = 당일 캔들의 저가 ≤ 20일 단순이동평균(SMA) ≤ 고가** (하루 범위가 20MA를 관통)
- **대장주 = ** 종가 > 200MA(상승추세) 이면서 RS(상대강도) 상위 N
- 데이터는 무료 소스(약간 지연된 종가). 일봉 종가 전략에는 충분하지만, 실시간 호가는 아닙니다.

## 주의

- GitHub Actions 무료 시간 한도 안에서 충분히 돕니다(하루 1회, 수 분).
- 예약 실행은 GitHub 부하에 따라 몇 분~수십 분 늦을 수 있습니다(정상).
- 첫 실행 로그(Actions 탭)에서 데이터 수집 건수를 확인하세요. 0건이면 알려주시면 소스를 고칩니다.
