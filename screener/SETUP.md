# 2트랙 모멘텀 스크리너 — 설치 가이드

매일 아침(07:10 KST) GitHub가 자동으로 돌려서 **미국·한국**의
**① 시장 건강도(레짐) → ② 강한 섹터·대장주 → ③ 20MA 눌림목 → ④ 추세 상태(주의/하락전환/하락추세)**
를 텔레그램으로 보내고, 대시보드(차트·이격도·엘리어트 추정)를 `reports/`에 저장합니다.
코드는 안 보셔도 되고, **텔레그램 봇 + 시크릿 2개**만 한 번 세팅하면 끝입니다.

---

## 1단계 — 텔레그램 봇 만들기 (5분, 무료)

1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 봇 이름·아이디 정하면 **봇 토큰**(예: `8123456:AA...`)을 줍니다.
2. 방금 만든 **내 봇**과 대화 시작 → 아무 말이나 한 번 전송(예: `hi`).
3. **chat_id 확인**: 브라우저에서 (토큰 자리에 본인 토큰)
   ```
   https://api.telegram.org/bot<봇토큰>/getUpdates
   ```
   결과의 `"chat":{"id":123456789` 숫자가 chat_id 입니다. (안 보이면 봇에 메시지 한 번 더 보내고 새로고침)

---

## 2단계 — GitHub 시크릿 등록

레포 → **Settings → Secrets and variables → Actions → New repository secret** 에서 2개 추가:

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | 1단계 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 1단계 chat_id |

> 시크릿은 암호화 저장되고 로그에도 안 보입니다. 코드·화면엔 절대 적지 마세요.

---

## 3단계 — 바로 실행해서 확인

레포 → **Actions** 탭 → **Daily Momentum Screener (2-track + regime)** → **Run workflow**.
- 텔레그램으로 메시지가 오면 성공.
- 결과: `reports/dashboard.html`(차트 대시보드), `reports/data.json`, `reports/latest.md`.

> ⚠️ **예약(매일 자동) 실행은 '기본 브랜치(main)'의 워크플로만 동작**합니다.
> 지금은 `claude/...` 작업 브랜치에 있으니, 매일 자동을 원하면 이 브랜치를 main에 머지하세요.
> 머지 전에도 **Run workflow(수동)** 는 이 브랜치에서 작동합니다.

## 무엇을 판단하나 (로직 요약)

**① 시장 건강도(레짐)** — StockEasy 방법론 재현
- 지수(S&P500·나스닥 / 코스피·코스닥) 200·50일선·정배열
- 시장 폭: 200/20일선 이탈 비율, 52주 신고가-신저가 순증
- → 🟢추세유지 / 🟡상승둔화·관망 / 🔴조정국면 + 한 줄 대전제

**② 강한 섹터 → 대장주 (트랙①)**
- 미국: SPDR 11 + 테마 ETF(SMH·IGV·XBI·ITA·TAN·JETS·KRE·XME·XOP)를 RS로 랭킹
- 한국: KODEX 섹터 ETF(반도체·2차전지·바이오·은행·증권·철강·자동차·건설·운송)를 RS로 랭킹
- 강한 섹터 top3 → 구성종목 중 RS 상위 대장주 3개

**③ 개별 RS Top10 (트랙②)** — 전체 유니버스 RS 상위 10, 최상위 3 심층

**④ 20MA 눌림목** — 당일 저가 ≤ 20일선 ≤ 고가 (캔들이 20MA에 닿음)

**⑤ 종목 추세 상태**
- 🟢 추세유지 · 🟡 주의(60MA 이탈·RSI 약세·고점 낮아짐)
- 🟠 하락전환(직전 스윙 저점 이탈, 아직 120선 위) · 🔴 하락추세(120선 이탈)

**🔥 핫한 종목** — 수동 리스트 없이 **유니버스 전체에서 자동 발굴**. 거래량 급증(20일평균 대비) +
단기 모멘텀(1주·1개월) + 신고가 근접을 결합한 **핫 점수(0~100)** 로 시장별 상위 N개를 노출.
상장 1년 미만이면 "신규상장" 배지가 붙어 같이 잡힙니다. (관리할 티커 없음)

**🎯 컨센서스 목표가** — **선택된 모멘텀 종목**(Top10·대장주·핫한 종목)만 애널리스트 컨센서스
목표주가를 조회해 **상승여력**(목표가 ÷ 현재가 − 1)·투자의견을 표시. 유니버스 전체가 아니라
실제 플레이 종목만 조회해 빠릅니다. **미국 = 야후(yfinance) 집계**(평균·최고·최저 + 애널 수),
**한국 = 네이버 증권 컨센서스**(코스피·코스닥 평균 목표가 + 투자의견). 상승여력 큰 순으로 정렬.

**원자재** — 금·은·구리·원유·천연가스·종합·우라늄·금광 ETF를 RS·눌림목으로 추적

> AI(클로드 API) 호출 없음 — 전부 순수 계산이라 **토큰 비용 0**. GitHub Actions 무료 시간만 사용.

## 자주 바꾸는 설정 (`screener/screener.py` 상단 `CONFIG`)

| 항목 | 의미 | 기본 |
|---|---|---|
| `ma_pullback` / `ma_trend` | 눌림목선 / 추세필터선(년선) | 20 / 240 |
| `top_sectors` / `leaders_per_sector` | 강한 섹터 수 / 섹터별 대장주 | 3 / 2 |
| `individual_top` / `deep_top` | 개별 Top N / 심층 수 | 10 / 3 |
| `hot_top_n` | 핫한 종목(거래량·단기급등) 상위 N | 8 |
| `rs_weights` | RS = 지수 대비 상대강도, 1·3·6개월 가중 | 0.3/0.4/0.3 |
| `zigzag_pct` | 엘리어트·스윙 임계치 | 7% |
| `kr_top_n` | 한국 시총 상위 N | 250 |

말로 "20MA 말고 60MA", "대장주 5개", "테마 ETF에 SOXX·CIBR 추가"처럼 알려주시면 제가 반영합니다.
