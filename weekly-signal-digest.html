모닝 다이제스트

한 주간의 인터뷰·리포트·영상을 에이전트가 대신 읽고, 출처가 검증된 인사이트만 한 화면에 남깁니다.

운용 관점페르소나 — "무엇을 중요하게 볼지"

📌 왜 먼저 정하나: 같은 자료라도 이 관점에 따라 HIGH로 뽑히는 항목이 달라집니다. 아래 문구를 본인 운용 컨텍스트로 바꾸면(개별 종목 담당·섹터·매크로 등) 등급이 다시 매겨집니다. 지금은 데모 기본값입니다.

결과 1위클리 시그널 — 3줄

📌 왜 3줄인가: 한 주를 한 호흡에 파악하도록, 운용 판단을 바꿀 수 있는 것만 정확히 3개로 압축합니다. 각 줄은 아래 인사이트 근거와 연결됩니다.

결과 2핵심 인사이트

📌 지금 무엇을 하나: 각 인사이트에 중요도(HIGH/MEDIUM)를 매기고, 반드시 원문 인용 + 출처를 답니다. 첫 HIGH는 '이번 주 핵심'으로 크게 띄웁니다(HIGH가 없으면 MEDIUM을 정직하게 'MEDIUM·이번 주 참고'로). 영상 출처는 ▶ mm:ss 에서 보기, 문서는 ▶ 원문에서 보기로 1차 자료에 바로 점프합니다.

결과 3볼 것 / 건너뛸 것

📌 왜 나누나: 입력된 모든 출처에 watch/skip 판정과 한 줄 이유를 답니다. 원문까지 봐야 할 것과 요약으로 충분한 것을 갈라 시간을 아낍니다.

✅ 볼 것 (원문 확인 권장)

⏭️ 건너뛸 것 (요약으로 충분)

결과 4검증 필요

📌 지금 무엇을 하나: 자동 자막·요약 기반이라, 주관적 전망·미확인 수치·모델 추정치는 본문 인사이트에 섞지 않고 여기로 분리합니다. 건너뛰지 마세요 — 의사결정 전에 사람이 원본으로 확인할 목록입니다.

어떻게 만드나에이전트 워크플로우

📌 왜 단계를 나누나: 수집은 모델 없이, 추출은 가벼운 모델, 최종 생성만 가장 똑똑한 모델로 — 비용은 줄이고 품질은 지킵니다. 각 단계가 무엇을 하는지 아래에 적었습니다.
단계 0

수집 (모델 없음)

유튜브 자막·문서 본문을 캐시에 저장. API 키 불필요. 200자 미만 본문은 버림.

키 없음
단계 1

Reader 추출 (보이지 않음)

문서 본문에서 사실·수치·목표가·의견만 압축. 본문에 없는 건 안 지어냄.

Sonnet 4.6 · medium
단계 2

소스 통합

영상 자막([초] 마커)과 추출문을 한 블록으로 합침. 발언 위치를 가리킬 수 있게.

코드
단계 3

다이제스트 생성 (보이는 단계)

페르소나+소스로 단 한 번 생성. emit_digest 도구로 구조화 제출.

Opus 4.8 · xhigh

입력자료 붙여넣기 (자동 수집은 건너뜀)

📌 가장 빠른 길: 자동 수집은 생략하고, 관심 있는 공개 리포트·자막 텍스트 2~3건을 붙여넣어 '생성 단계'부터 돌립니다. 유튜브 자막은 영상의 "스크립트 표시"에서, 리포트 본문은 발행처 공개 PDF에서 얻습니다. 공개 자료만 — 내부 자료는 넣지 마세요.

구독채널 카탈로그 (공개 자료만)

📌 무엇인가: 결과를 먼저 보고, 그 아래에서 어떤 공개 채널을 정기적으로 모을지 고릅니다. '베스트에포트'(Apollo·한국은행)는 사이트 구조상 자동 수집이 보장되지 않아 기본 선택에서 빠져 있습니다.
